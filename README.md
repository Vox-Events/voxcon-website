[![GitHub Pages](https://github.com/Vox-Events/voxcon-website/actions/workflows/pages.yml/badge.svg)](https://github.com/Vox-Events/voxcon-website/actions/workflows/pages.yml)

## Quick-start

Requirements to build:
- Golang
- Node
- Make

```shell
$ npm i
$ make build # or make watch
```

Source pages are kept in `./src/content`.  
Translation files are kept in `./i18n`.
